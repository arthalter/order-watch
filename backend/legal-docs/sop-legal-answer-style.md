# SOP：法律问答答复边界与免责声明

## 适用场景
- 用户询问法律文档条款、材料清单、时间节点、查询步骤或答复边界时的回答组织。

## 答复结构
1. 先说明当前回答基于已入库文档和命中的 SOP，不代表正式法律意见。
2. 分开列出命中文档、关键条款或材料、依据来源和建议补充方向。
3. 对检索结果没有覆盖的信息，明确写“当前文档未检索到”。
4. 对需要执业律师或人工法务判断的问题，提示人工复核。

## 禁止事项
- 不编造不存在的法条、判例、合同条款或材料。
- 不承诺胜诉概率、赔偿金额或最终处理结果。
- 不在文档依据不足时给出确定性结论。

## 推荐表达
- “基于当前已入库文档，命中的关键内容是……”
- “当前检索到的材料包括……”
- “建议补充以下文档后再由人工法务复核……”
- “该结论仅用于学习项目演示，不构成正式法律意见。”
