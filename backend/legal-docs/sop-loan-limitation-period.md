# SOP：借款纠纷诉讼时效查询指引

## 适用场景
- 民间借贷、企业借款、欠款确认、还款承诺等材料中需要查询诉讼时效相关节点。

## 核查重点
- 借款合同或借条中是否写明还款日期。
- 到期后是否存在催收记录、部分还款、对账确认、还款计划或重新承诺。
- 相关记录是否包含主体、时间、内容和对应债务。
- 是否存在诉讼、仲裁、调解等能够中断或影响时效的程序材料。

## 处理步骤
1. 提取借款日期、到期日期、最后一次还款或催收日期。
2. 按时间线排列材料，并标记每条材料对应的事实节点。
3. 对接近或超过三年的区间，列出需要继续检索的中断或确认材料。
4. 输出需要补充的材料，例如转账记录、聊天记录、电话录音摘要、对账单或还款承诺。

## 输出边界
- 可以提示诉讼时效相关时间节点和材料缺口。
- 不直接承诺案件胜诉概率。
- 对时间节点存在争议的，必须提示人工法务结合完整材料判断。
