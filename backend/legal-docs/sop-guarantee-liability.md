# SOP：保证责任查询指引

## 适用场景
- 保证合同、借款合同中的保证条款，以及债权人要求保证人承担责任时的文档查询。

## 核查重点
- 保证方式：核查文本是否明确写明一般保证或连带责任保证。
- 保证期间：核查约定期间、起算节点，以及是否存在债权人依法主张权利的材料。
- 主债务范围：核查本金、利息、违约金、损害赔偿金和实现债权费用是否被纳入保证范围。
- 主债务状态：核查债务履行期限、到期事实、还款或展期约定。

## 处理步骤
1. 摘录保证条款原文，并标记保证方式、保证期间和担保范围。
2. 结合主合同确认债务金额、到期日及违约约定。
3. 检索催收通知、送达记录、还款记录或其他主张权利材料。
4. 对未明确约定或材料缺失之处，形成待补充清单后交由人工法务核查。

## 输出边界
- 可以提示应核查的条款字段和当前文档片段。
- 不在材料不完整时直接判断保证人最终应承担的责任范围。
- 涉及诉讼策略、时效届满争议或重大金额时，应提示人工法律复核。
